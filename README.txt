
==================================== HOW TO SET UP ===============================

Install Logitech G Hub and open it. Create a new profile for your game. Make a new script and paste the contents from "NO RECOIL" into the script editor. Assign a toggle key (Default capslock) to activate recoil control. Once set up, test in the shooting range by aiming and firing to ensure recoil control is functioning properly.

This script was made for 1600 dpi and 4-4 in game sens, you can adjust the preset values according to what suits you best.
